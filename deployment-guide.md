# Deployment Guide

This guide explains how to build, run, verify, manage, and clean up the Dockerized Flask Web Application on your local machine.

---

### 📋 Prerequisites

Before you begin, ensure you have:

- Docker Engine or Docker Desktop installed
- Docker running successfully
- Git installed
- A web browser
- Basic familiarity with the command line
- Basic knowledge of Python and Flask

Verify the Docker installation:

```bash
docker --version
docker ps
````

---

### 📂 Clone the Repository

Clone the project and navigate into the project directory.

```bash
git clone https://github.com/Knandwani07/dockerized-flask-app.git
cd dockerized-flask-app
```

---

### 📁 Navigate to the Application Directory

The Flask application files are organized inside the `app/` directory.

```bash
cd app
```

Verify the application files:

```bash
ls
```

Expected structure:

```text
app.py
requirements.txt
visits.txt
templates/
```

---

### 🏗️ Build the Docker Image

Build the Docker image using the Dockerfile located in the project directory.

If the Dockerfile is located at the repository root, run:

```bash
docker build -t flask-docker-app .
```

Verify that the Docker image was created successfully:

```bash
docker images
```

Expected output:

```text
REPOSITORY          TAG       IMAGE ID
flask-docker-app    latest    xxxxxxxxxxxx
```

The Docker image packages the Flask application, Python environment, dependencies, and required application files into a portable container image.

---

### ▶️ Run the Container

Launch a container from the newly created Docker image.

```bash
docker run -d -p 5000:5000 --name flask-container flask-docker-app
```

The `-d` option runs the container in detached mode, while `-p 5000:5000` maps port `5000` on the host machine to port `5000` inside the container.

Verify that the container is running:

```bash
docker ps
```

Expected output:

```text
CONTAINER ID   IMAGE              PORTS
xxxxxxxxxxxx   flask-docker-app   0.0.0.0:5000->5000/tcp
```

---

### 🌐 Access the Application

Open a web browser and navigate to:

```text
http://localhost:5000
```

The Flask application should load successfully.

The application processes the request, reads the current visit count from `visits.txt`, updates the counter, and renders the `index.html` template.

---

### 🔢 Verify the Visit Counter

Refresh the webpage several times.

The visit counter should increment with every request:

```text
Visit Count: 1
Visit Count: 2
Visit Count: 3
Visit Count: 4
```

This verifies that the Flask application is successfully processing requests and updating the visit count.

---

### 📜 View Container Logs

View the logs generated by the Flask container:

```bash
docker logs flask-container
```

To continuously monitor the container logs:

```bash
docker logs -f flask-container
```

Press `Ctrl + C` to stop following the logs.

---

### 🖥️ Access the Running Container

Open an interactive shell inside the running container:

```bash
docker exec -it flask-container bash
```

Navigate to the application directory:

```bash
cd /app
```

List the application files:

```bash
ls
```

Expected output:

```text
app.py
requirements.txt
visits.txt
templates
```

Check the current visit count:

```bash
cat visits.txt
```

Exit the container:

```bash
exit
```

---

### 🔍 Inspect the Container

Display detailed information about the running container:

```bash
docker inspect flask-container
```

Check the container's resource usage:

```bash
docker stats flask-container
```

Press `Ctrl + C` to stop the live statistics display.

---

### ⏹️ Stop the Container

Stop the running Flask container:

```bash
docker stop flask-container
```

Verify that the container has stopped:

```bash
docker ps
```

The stopped container will no longer appear in the list of running containers.

---

### 🔄 Restart the Container

Start the previously stopped container:

```bash
docker start flask-container
```

Verify that it is running:

```bash
docker ps
```

The application should once again be available at:

```text
http://localhost:5000
```

---

### 🗑️ Remove the Container

Stop the container before removing it:

```bash
docker stop flask-container
```

Remove the stopped container:

```bash
docker rm flask-container
```

Verify that the container has been removed:

```bash
docker ps -a
```

---

### 🧹 Remove the Docker Image

Remove the Docker image created for the application:

```bash
docker rmi flask-docker-app
```

Verify that the image has been removed:

```bash
docker images
```

---

### 🧹 Clean Up Project Files

After completing the Docker deployment, remove the application files and project directory if you want to return the workspace to its original state.

From the parent directory:

```bash
rm -rf flask-docker-app
```

Verify that the project directory has been removed:

```bash
ls
```

> **Windows PowerShell:**

```powershell
Remove-Item -Recurse -Force flask-docker-app
```

---

### ✅ Deployment Verification Checklist

* Docker is installed and running.
* Repository is cloned successfully.
* Flask application files are present.
* Docker image builds successfully.
* Flask container starts successfully.
* Application is accessible at **[http://localhost:5000](http://localhost:5000)**.
* Visit counter increments when the page is refreshed.
* Container logs can be viewed successfully.
* Running container can be inspected.
* Container can be stopped and restarted.
* Container can be removed successfully.
* Docker image can be removed successfully.

---

### 🎉 Deployment Complete

Your **Dockerized Flask Web Application** is now successfully deployed and running inside a Docker container.

You have completed the complete deployment workflow, including **Docker image creation, container execution, port mapping, application verification, visit-counter testing, log inspection, container management, and resource cleanup**.
