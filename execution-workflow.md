# 🛠️ Execution Workflow

This guide walks through the complete process of creating, containerizing, running, verifying, and cleaning up the Flask web application using Docker.

---

## I. Create the Project Directory

Create a dedicated project directory and navigate into it.

```bash
mkdir flask-docker-app
cd flask-docker-app
````

Verify the current working directory:

```bash
pwd
```

All application files and Docker resources will be organized within this directory.

---

## II. Create the Flask Application

Create the main Flask application file:

```bash
touch app.py
```

Add the Flask application code to `app.py`.

The application handles incoming HTTP requests, reads the current visit count from `visits.txt`, increments the counter, and renders the HTML template.

---

## III. Create the Templates Directory

Create the directory used by Flask to store HTML templates:

```bash
mkdir templates
```

Create the main HTML template:

```bash
touch templates/index.html
```

Add the HTML content to `index.html`.

The template displays the visit count generated by the Flask application.

Verify the project structure:

```bash
tree
```

Expected structure:

```text
flask-docker-app/
├── app.py
└── templates/
    └── index.html
```

---

## IV. Create Supporting Files

### A. Create requirements.txt

Create the dependency file:

```bash
touch requirements.txt
```

Add the required Flask dependency:

```text
Flask
```

Verify the file:

```bash
cat requirements.txt
```

---

### B. Create visits.txt

Create the file used to store the visit count:

```bash
touch visits.txt
```

Initialize the counter with:

```text
0
```

Verify the counter:

```bash
cat visits.txt
```

---

### C. Create .dockerignore

Create the Docker build context configuration:

```bash
touch .dockerignore
```

Add the files and directories that should be excluded from the Docker build context.

Verify the configuration:

```bash
cat .dockerignore
```

---

## V. Create the Dockerfile

Create the Dockerfile:

```bash
touch Dockerfile
```

Add the Docker build instructions to the file.

The Dockerfile defines the Python base image, application working directory, dependency installation, application files, exposed port, and startup command.

Verify the Dockerfile:

```bash
cat Dockerfile
```

Inspect the complete project structure:

```bash
tree
```

---

## VI. Build the Docker Image

Build the Docker image from the project directory:

```bash
docker build -t flask-docker-app .
```

Verify that the image was created successfully:

```bash
docker images
```

The output should contain:

```text
flask-docker-app
```

---

## VII. Run the Container

Create and start a container from the Docker image:

```bash
docker run -d -p 5000:5000 --name flask-container flask-docker-app
```

Verify that the container is running:

```bash
docker ps
```

The container should show port mapping similar to:

```text
0.0.0.0:5000->5000/tcp
```

---

## VIII. Verify the Application

Open the application in a web browser:

```text
http://localhost:5000
```

The Flask application should load successfully.

Refresh the page several times to verify that the visit counter increments:

```text
Visit Count: 1
Visit Count: 2
Visit Count: 3
Visit Count: 4
```

This confirms that the Flask application is successfully running inside the Docker container.

---

## IX. Inspect the Container

View the container logs:

```bash
docker logs flask-container
```

Access the running container:

```bash
docker exec -it flask-container bash
```

Navigate to the application directory:

```bash
cd /app
ls
```

Check the visit counter:

```bash
cat visits.txt
```

Exit the container:

```bash
exit
```

---

## X. Stop and Restart the Container

Stop the running container:

```bash
docker stop flask-container
```

Restart the container:

```bash
docker start flask-container
```

Verify that the container is running again:

```bash
docker ps
```

Access the application again:

```text
http://localhost:5000
```

---

## XI. Clean Up Docker Resources

Stop the container:

```bash
docker stop flask-container
```

Remove the container:

```bash
docker rm flask-container
```

Verify that the container has been removed:

```bash
docker ps -a
```

Remove the Docker image:

```bash
docker rmi flask-docker-app
```

Verify that the image has been removed:

```bash
docker images
```

---


The project demonstrates the complete lifecycle of a Dockerized Flask application, from application creation and image building to container execution, verification, management, and cleanup.
